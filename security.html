nostr.chat · Privacy

Security

Plain statements about what protects you, what does not, and how to report a problem.

Messages

Direct messages use NIP-17: the message is sealed and gift-wrapped with NIP-44 encryption, so relays carry only an opaque envelope from a throwaway key. Only the recipient and you can read it. Optionally, chats with Iris-compatible contacts can use a Signal-style double ratchet, which adds forward secrecy: a key stolen later cannot decrypt earlier messages. Public rooms are public; anyone can read them.

Identity and keys

You are a key pair. The private key never leaves your browser, extension or remote signer, and we cannot reset or recover it. Anyone with your private key is you; keep the backup from Settings safe. A profile's NIP-05 address is only shown as verified after a direct check against that domain.

The code you run

nostr.chat is static files with no build step. Every library is vendored and pinned, with recorded checksums that are checked in continuous integration, and the page's Content Security Policy allows scripts from this origin only. There is no runtime dependency on a CDN. All events from relays and directories are signature-verified on your device before anything trusts them.

Deletion

Deleting your own message publishes a standard deletion request that well-behaved relays and clients honour, but it cannot force every copy to disappear. "Delete for me" hides a message on your devices only. Only the author's own deletion request removes a message from view; nobody else's can.

Rooms

A room's owner decides who is trusted and who is blocked. Links from untrusted members are shown as plain text and their media is not loaded, which limits what a stranger can make your browser fetch.

Limits you should know

  • Relays see your IP address and when you are online. nostr.chat is not an anonymity tool; use it over a VPN or Tor if that matters to you.
  • Standard NIP-17 messages have no forward secrecy: a private key stolen later can decrypt past envelopes still held on relays.
  • Double-ratchet messages reach every device you have registered, but a device added later does not get earlier history, and clearing a browser's storage loses what it held.
  • A compromised device, browser extension or signer can read what you can read.
  • There are no push notifications while the tab is closed.

Reporting

Found a vulnerability? Please open an issue at github.com/melvincarvalho/anagram/issues, or, for something sensitive, send the maintainer an encrypted direct message from inside nostr.chat.
